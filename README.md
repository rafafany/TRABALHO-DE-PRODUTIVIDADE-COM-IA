# Trabalho de Produtividade

## Sobre o trabalho

Este repositório apresenta os materiais desenvolvidos para o trabalho acadêmico sobre **Produtividade**, com foco na relação entre Inteligência Artificial e desenvolvimento de software.

O trabalho discute se o uso de ferramentas de Inteligência Artificial realmente torna os desenvolvedores mais produtivos, considerando aspectos como velocidade, qualidade, segurança, tomada de decisão, percepção de produtividade e os custos associados ao uso dessas tecnologias.

Também são analisados casos práticos envolvendo o uso de Inteligência Artificial no desenvolvimento de software, incluindo experiências da Spotify e o caso de segurança envolvendo a Samsung.

Outro ponto abordado é a relação entre produtividade e sustentabilidade, incluindo o **Paradoxo de Jevons**, que permite discutir como ganhos de eficiência podem estimular maior utilização de uma tecnologia e, consequentemente, aumentar o consumo total de recursos.
